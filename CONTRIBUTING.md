# Contributing to GPT Tips & Tricks

Thanks for wanting to contribute! This project grows through shared, tested prompts — here's how to add yours.

## How to Add a Prompt

1. **Fork** this repository
2. **Clone** your fork locally
3. Add your prompt to the relevant file in `prompts/` (or create a new file if it doesn't fit an existing category)
4. Follow the existing format:
   - A short `##` heading naming the prompt
   - A one-line description of what it's for (optional but encouraged)
   - The prompt itself inside a ` ```text ` code block, using `[BRACKETS]` for user-filled values
5. **Commit** your changes with a clear message, e.g. `Add prompt for explaining regex`
6. **Push** to your fork and open a **Pull Request** against `main`

## Guidelines

- Keep prompts practical — something you've actually tested and found useful
- Keep descriptions short and beginner-friendly
- One prompt per addition is fine; you don't need to batch multiple in one PR
- If you're adding a new category, create a new file in `prompts/` and link it in the README's "What's Inside" table

## Reporting Issues

Found a prompt that doesn't work well, or have an idea for improvement? Open an [issue](../../issues) — feedback is welcome too.
