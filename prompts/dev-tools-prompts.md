# 🧰 Dev Tools Prompts

Prompts for the small tools beginners get stuck on: Git, the terminal, SQL, and regex.

## 1. Fix a Git Problem

```text
I'm stuck with a Git problem. Help me fix it safely.

What I was trying to do: [DESCRIBE YOUR GOAL]
What happened: [DESCRIBE THE PROBLEM OR PASTE THE ERROR]
Output of `git status`: [PASTE OUTPUT]

Please:
1. Explain what went wrong in simple terms
2. Give me the commands to fix it, one step at a time
3. Warn me before any command that could delete or overwrite my work
4. Tell me how to avoid this problem next time
```

## 2. Explain a Terminal Command

```text
Explain this terminal command to me as a beginner.

Command: [PASTE COMMAND HERE]

Please:
1. Break it down piece by piece (command, flags, arguments)
2. Explain what it will do when I run it
3. Tell me if it could be dangerous or change/delete anything
4. Show a safer way to test it first, if there is one
```

## 3. Write a SQL Query

```text
Help me write a SQL query.

My tables and columns:
[DESCRIBE OR PASTE YOUR TABLE STRUCTURE]

What I want to get: [DESCRIBE THE RESULT IN PLAIN ENGLISH]

Please:
1. Write the query
2. Explain each part of it line by line
3. Mention any assumptions you made
4. Suggest one way to test that the result is correct
```

## 4. Write and Explain a Regex

```text
Write a regular expression for this task.

What I want to match: [DESCRIBE THE PATTERN]
Language/tool: [e.g. Python, JavaScript, grep]

Examples that should match:
[LIST EXAMPLES]

Examples that should NOT match:
[LIST EXAMPLES]

Please give me the regex, explain each part in simple terms, and show how to use it in code.
```

## 5. Set Up a Development Environment

```text
Help me set up my development environment for [LANGUAGE OR FRAMEWORK].

My operating system: [WINDOWS/MAC/LINUX]
My experience level: [BEGINNER/INTERMEDIATE]

Please give me:
1. The tools I need to install and why
2. Step-by-step installation instructions
3. A simple command or program to check that everything works
4. The most common setup mistakes and how to avoid them
```
