# 💻 Coding Prompts

A collection of GPT prompts I find useful while learning software development.

## 1. Explain Code Like a Beginner

```text
Explain this code step by step as if I am a beginner learning programming.

For each important line, explain:
1. What it does
2. Why it is needed
3. What would happen if it were removed or changed

Code:
[PASTE CODE HERE]
```

## 2. Code Review & Improvement Suggestions

```text
Review this code and suggest improvements.

Please cover:
1. Readability — is the code easy to understand?
2. Best practices — does it follow common conventions for this language?
3. Potential bugs or edge cases I might have missed
4. One or two specific ways I could improve it, with example code

Code:
[PASTE CODE HERE]
```

## 3. Write Tests for My Code

```text
Write tests for this code.

Please:
1. Identify the main cases that should be tested (including edge cases)
2. Write the tests using [TESTING FRAMEWORK, e.g. Jest, PyTest, JUnit]
3. Briefly explain what each test checks

Code:
[PASTE CODE HERE]
```

## 4. Refactor & Optimize Code

```text
Refactor this code to make it cleaner and more efficient.

Please:
1. Point out what is inefficient or hard to maintain in the current version
2. Show the refactored code
3. Explain each significant change and why it's an improvement
4. Tell me if the behavior of the code changes in any way

Code:
[PASTE CODE HERE]
```
