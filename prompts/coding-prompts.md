# 💻 Coding Prompts

A collection of GPT prompts I find useful while learning software development.

## 1. Explain Code Like a Beginner

```text
Explain this code step by step as if I am a beginner learning programming.

For each important line, explain:
1. What it does
2. Why it is needed
3. What would happen if it were removed or changed

Code:
[PASTE CODE HERE]
```
