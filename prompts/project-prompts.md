# 🛠️ Project Prompts

Prompts for coming up with project ideas and planning them out with GPT.

## 1. Generate Project Ideas

```text
Suggest 5 project ideas for a [BEGINNER/INTERMEDIATE/ADVANCED] developer who wants to practice [SKILL OR TECHNOLOGY, e.g. React, Python, APIs].

For each idea, include:
1. A short description
2. The main skills it will help me practice
3. Roughly how long it might take to build
4. One way to make it harder if I want an extra challenge
```

## 2. Turn an Idea into a Plan

```text
I want to build this project: [DESCRIBE YOUR PROJECT IDEA]

Help me turn it into a simple plan. Please include:
1. Core features (the minimum to make it work)
2. Optional/stretch features I can add later
3. A suggested tech stack, with a short reason for each choice
4. A rough step-by-step build order
```

## 3. Break a Project into Tasks

```text
Here is my project: [DESCRIBE YOUR PROJECT]

Break it down into small, specific tasks I can complete one at a time.
Group the tasks into phases (e.g. setup, core features, polish, testing).
For each task, keep it small enough to finish in a single coding session.
```

## 4. Review My Project Scope

```text
Here is my project idea: [DESCRIBE YOUR PROJECT]
Here is what I plan to include: [LIST YOUR PLANNED FEATURES]

Please tell me:
1. If the scope is realistic for a [TIMEFRAME, e.g. weekend, 2 weeks, 1 month]
2. Any features I should cut or simplify to finish on time
3. Any features I might be missing that are commonly expected
```
