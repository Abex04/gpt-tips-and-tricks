# 💼 Interview & Career Prompts

Prompts for preparing for interviews, improving your resume, and presenting your projects.

## 1. Mock Technical Interview

```text
Act as a technical interviewer for a [JOB ROLE, e.g. junior web developer] position.

Please:
1. Ask me one interview question at a time
2. Wait for my answer before continuing
3. After each answer, give feedback on what was good and what was missing
4. Gradually increase the difficulty
5. After 5 questions, give me an overall assessment and topics to review

Start with the first question.
```

## 2. Prepare for Behavioral Questions

```text
Help me prepare for behavioral interview questions for a [JOB ROLE] position.

Please:
1. Give me 5 common behavioral questions for this role
2. Explain what the interviewer is really looking for in each
3. Show me how to structure an answer using the STAR method (Situation, Task, Action, Result)
4. Then ask me to try answering one, and give me feedback

My background: [BRIEFLY DESCRIBE YOUR EXPERIENCE]
```

## 3. Improve My Resume

```text
Review my resume and suggest improvements.

Target role: [JOB ROLE]

Please:
1. Point out weak or vague bullet points
2. Rewrite them to be specific and results-focused
3. Suggest anything important that seems to be missing
4. Flag anything that could be cut or shortened

Resume:
[PASTE RESUME TEXT HERE]
```

## 4. Describe My Project for a Resume

```text
Turn this project into 2-3 strong resume bullet points.

Project: [DESCRIBE WHAT YOU BUILT]
Tech used: [LANGUAGES / TOOLS]
What I did: [YOUR SPECIFIC CONTRIBUTIONS]

Each bullet should:
1. Start with a strong action verb
2. Mention the technology used
3. Show the result or impact, if possible

Do not invent numbers or facts I haven't given you.
```

## 5. Explain My Project in an Interview

```text
Help me prepare to talk about this project in an interview.

Project: [DESCRIBE YOUR PROJECT]

Please:
1. Write a 30-second summary I can say out loud
2. List 5 questions an interviewer might ask about it
3. Suggest what I should be ready to explain about my technical choices
4. Point out any weak spots in the project that I should be prepared to discuss honestly
```
