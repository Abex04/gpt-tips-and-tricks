# 📚 Study Prompts

Prompts for using GPT as a study assistant.

## 1. Learn a Topic

```text
Teach me [TOPIC] as a beginner.

Please explain:
1. The basic idea
2. A simple real-world example
3. The most important concepts
4. Common mistakes
5. Give me a short practice exercise

Do not give me the answer to the exercise until I try it.
```

## 2. Create a Study Plan

```text
Create a realistic study plan for learning [TOPIC].

My current level: [BEGINNER/INTERMEDIATE/ADVANCED]
Time available each day: [TIME]
Goal: [GOAL]

Break the plan into small daily tasks and include practice exercises.
```
