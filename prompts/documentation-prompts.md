# 📝 Documentation & Writing Prompts

Prompts for writing clear documentation, commit messages, and code comments.

## 1. Write a README

```text
Write a professional README.md for my project.

Project name: [NAME]
What it does: [SHORT DESCRIPTION]
Tech used: [LANGUAGES / FRAMEWORKS]
Key features: [LIST FEATURES]

Include these sections:
1. Short description
2. Features
3. Installation steps
4. Usage example
5. Contributing
6. License

Keep the tone clear and beginner-friendly.
```

## 2. Write a Good Commit Message

```text
Write a clear git commit message for these changes.

Follow this format:
- A short summary line (max 50 characters, imperative mood, e.g. "Add login validation")
- A blank line
- An optional body explaining what changed and why

Changes:
[PASTE YOUR DIFF OR DESCRIBE WHAT YOU CHANGED]
```

## 3. Add Comments to My Code

```text
Add helpful comments to this code.

Please:
1. Explain the purpose of each function at the top of it
2. Comment only the parts that are not obvious
3. Avoid stating the obvious (e.g. don't write "increment i" next to i++)
4. Keep comments short and clear

Code:
[PASTE CODE HERE]
```

## 4. Write Documentation for a Function or API

```text
Write documentation for this function/API endpoint.

Please include:
1. A one-line summary of what it does
2. Parameters (name, type, description)
3. Return value
4. A short usage example
5. Any errors or edge cases to be aware of

Code:
[PASTE CODE HERE]
```

## 5. Explain My Project to Others

```text
Help me explain my project to a non-technical person in 3-4 sentences.

Project: [DESCRIBE YOUR PROJECT]

Then write a second version aimed at a technical audience (like a recruiter or another developer) that mentions the tech stack and what problem it solves.
```
