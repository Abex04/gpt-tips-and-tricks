## 📖 About

This project is a growing collection of GPT prompts, tips, and experiments tested while learning software development and exploring AI-assisted workflows.

The goal is simple: try useful techniques, document the results, and share what works — so other students and developers can skip the trial and error.

## 🚀 Example

From `debugging-prompts.md`:

```text
Analyze this code and find the bug.

Please:
1. Identify the problem
2. Explain why it happens
3. Show the corrected code
4. Explain the fix in simple terms

Code:
[PASTE CODE HERE]
```

Just copy a prompt, fill in the `[BRACKETS]`, and paste it into ChatGPT or any GPT-based tool.
